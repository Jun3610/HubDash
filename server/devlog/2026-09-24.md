- 스케줄(cron)은 "서버가 계속 켜져 있다"는 가정을 깔고 있다 — 운영 방식을 바꾸면(필요할 때만 켜기) 시간 기반 작업이 조용히 안 돌 수 있어, 기동 시 따라잡기가 같이 필요하다
- 데이터 보정은 "대상 컬럼 구분(시스템 기록 vs 사용자 입력) → 기준 시점 → 모호 구간 0건 확인 → 백업 → 한 트랜잭션"으로 하면 되돌릴 수 있고 설명할 수 있다

- 실제 메모 6개 + 과목 메모 왕복 확인: 5개 동일(1개는 목록 앞 빈 줄만), 1개는 목록 안 이어지는 줄 들여쓰기만 다름, 두 번 돌려도 같음
- 실서버 검증(headless Chrome): 새 메모에 입력 → H1·P·UL·할 일·인용으로 바로 바뀌고 DB에 "# 큰 제목\n\n**굵게** 그리고 1g << 2g -> 산책 [2027-1]…"로 저장, ⌘S로 과목 메모 저장, 메모·과목·설정·식단·주제·습관·검색 창 모두 Esc로 닫힘, 메모 6개를 열고 눌러도 수정 시각 그대로. 검증용 메모와 과목 메모는 지움

### 막힌 것
- @tiptap/markdown이 [ ] ~ < > 를 늘 \[ 나 &lt; 로 저장 → encodeTextForMarkdown을 바꿔 링크·취소선·HTML 태그·줄 맨 앞 # > 일 때만
