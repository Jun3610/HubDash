- 마크다운은 라이브러리 없이 React 요소로 그리는 렌더러로 구현 — innerHTML을 안 써서 메모에 `<script>`가 있어도 글자로만 보임
- 실서버 검증: 제목만 입력 → "내용을 입력하면 저장돼요"(요청 0건) → 본문 입력 → `POST` 1건, 주소 `?id=7` → 계속 입력 → 멈출 때마다 `PUT` 1건(키 입력마다가 아님) → 태그 추가 → 미리보기에서 제목·굵게 렌더, script 요소 0개·alert 없음 → 검색 → 삭제 `DELETE` 204

### 막힌 것
- 방금 만든 메모가 "8시간 전"으로 표시됨
→ 원인: API 컨테이너 시간대가 UTC(`date`로 확인: KST 09:28 = 컨테이너 00:28 UTC). LocalDateTime.now()로 찍는 createdAt/updatedAt이 UTC 벽시계로 저장되는데, 클라이언트는 시간대 없는 값을 로컬(KST)로 읽음 → 9시간 차이
→ 해결: 클라이언트 문제가 아니라 서버 설정 문제라 별도 이슈로 분리

### 배운 것
- 시간대 없는 LocalDateTime은 "누가 어느 시계로 찍었는지"가 약속이어야 한다 — 사용자 입력값(일정 시각)은 KST로 맞았지만 서버가 자동으로 찍는 값만 UTC였다. 목 서버로는 절대 안 드러나는 문제라 실서버 확인이 필요했음
