- `./gradlew build` 전체(H2 기반 기존 테스트 + 새 Testcontainers 테스트) 통과 확인

### 막힌 것
- Spring Boot 4.1.1이 관리하는 `org.testcontainers:testcontainers` 버전(2.0.5)에 대응하는 `junit-jupiter`/`postgresql` 모듈이 Maven Central에 아직 없음(그쪽은 1.21.4가 최신)
→ 원인: Testcontainers 코어가 2.x로 메이저업 됐지만 부속 모듈은 아직 1.21.4에 머물러 있어 릴리스 시점이 갈림
→ 해결: 세 아티팩트 전부 `1.21.4`로 명시 고정해서 Spring Boot 기본 관리 버전(2.0.5)을 오버라이드

### 배운 것
- Spring Boot BOM이 관리하는 버전이 항상 그 라이브러리 생태계 전체와 발맞춰 있는 건 아니다 — 코어와 부속 모듈의 릴리스 시점이 갈리면 명시적 버전 고정이 필요할 수 있음, 의존성 추가 후엔 항상 실제 resolve까지 확인하는 습관이 필요
- 이 테스트는 Docker가 있어야 돌아가므로, 앞으로 이 저장소에서 `./gradlew build`를 실행하는 모든 작업(도메인 추가 등)이 이제 Docker 실행을 전제로 함 — CI를 나중에 붙일 때 Docker-in-Docker 또는 Testcontainers Cloud 설정이 필요해짐
